# 流量特征

> **本版本线协议版本为 4；两端必须使用同一版本，否则会话会在握手阶段失败。**

## V0.2 删除了流量模式配置

Go V0.1 的 `trafficPattern`（以及服务端的 `dns`）配置在 Rust V0.2 中只被解析，从未进入真实数据路径：驱动层不读取它们，握手与会话 nonce 全部来自随机数。保留这些开关只会造成「流量可以被配置成另一种协议」的错觉，因此 V0.2 将其整体删除。旧配置文件若仍含这些字段，会被 serde 作为未知字段静默忽略，不影响加载。

当前真正影响流量形态的是协议层的固定行为，没有配置项可以调整：

- 每条消息使用协议层随机生成的 24 字节 nonce；配置层不再暴露 nonce 前缀改写接口。
- 元数据与会话控制等头部全部由协商出的 AEAD 保护，旁观者看不到明文头字段。
- 数据段带随机长度的前缀/后缀填充；UDP 使用混淆信封；会话使用随机会话 ID。这些值由协议层随机生成，不来自配置文件。

> **重要**：没有任何配置开关能让 shadowlemon 的流量「看起来像 HTTPS、QUIC 或其他协议」。请勿据此承诺抗识别能力。

可用配置字段见 `rust/docs/config-v0.2.md`，线格式细节见 `rust/docs/protocol-v0.2.md`。
